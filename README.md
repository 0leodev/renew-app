# RENEW

A **React Native (Expo) religious app** built for Android, designed to make devotional writing and Bible study easier.

## Features

* **Bible API Integration** – Quickly insert scripture into devotionals
* **PDF Generation & Text Sharing** – Export and share devotionals effortlessly
* **AdMob Integration** – Monetization with banner ads (+58 banner requests in beta)
* **Multilingual Support** – English & Spanish
* **Fast Development** – Delivered in just 30 days

## 🛠 Tech Stack

* **React Native (Expo)**
* **TypeScript**
* **AdMob**

## Platform

* Android
